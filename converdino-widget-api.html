Eigener Button, kein Design-Bruch

Das Converdino Web-Chat-Widget bietet eine JavaScript-API. Damit lässt sich der Chat aus einem beliebigen eigenen Element (Button, Link, Menüpunkt) öffnen — der mitgelieferte Standard-Button kann dabei abgeschaltet werden, sodass er nahtlos in Ihr eigenes Design passt.

1. Einbindung

Eine Zeile lädt das Widget. Mit data-launcher="off" erscheint kein eigener Button — Sie steuern das Öffnen selbst über die API.

<script
  src="https://converto-server-production.up.railway.app/converdino-widget.js"
  data-bot="IHR-BOT-CODE"
  data-launcher="off"></script>

Lassen Sie data-launcher weg, erscheint der mitgelieferte schwebende Button wie gewohnt.

2. Eigenen Button anbinden

Hängen Sie einen beliebigen Klick an die API. Beispiel mit Ihrem eigenen, ins Design passenden Button:

<button class="meine-pille" onclick="ConverdinoWidget.open()">
  Mit Berater chatten
</button>

Das Widget-Script und Ihr Button können in beliebiger Reihenfolge im HTML stehen — die API ist verfügbar, sobald das Script geladen ist (siehe Abschnitt 5).

3. API-Methoden — window.ConverdinoWidget

MethodeWirkung
open()Öffnet das Auswahl-Fenster (WhatsApp / Browser-Chat). Bei data-mode="web" erscheint dort nur der Browser-Chat.
openWebChat()Öffnet direkt den Browser-Chat und überspringt die Auswahl.
openChooser()Alias zu open() — öffnet das Auswahl-Fenster.
close()Schließt alle Fenster.
toggle()Öffnet, wenn geschlossen; schließt, wenn offen.
botCode(Eigenschaft) Der konfigurierte Bot-Code als String.
version(Eigenschaft) Versionskennung der API.

4. Konfiguration über data-Attribute

AttributWerte / StandardBedeutung
data-botz. B. Anfrage-XXXX · PflichtBot-Code des Slots.
data-modeweb · Standard: beideweb = Auswahl zeigt nur Browser-Chat, keine WhatsApp-Option.
data-launcheron (Standard) / offoff = kein mitgelieferter Button; Öffnen nur per API.
data-positionunten-rechts (Standard) / unten-links / oben-rechts / oben-linksEcke des schwebenden Buttons (nur relevant, wenn Launcher aktiv).
data-offset-xZahl · Standard 24Seitlicher Abstand zur Ecke in Pixeln.
data-offset-yZahl · Standard 24Abstand nach oben/unten zur Ecke in Pixeln.
data-waTelefonnummer · Standard zentrale NummerÜberschreibt die WhatsApp-Zielnummer.
data-apiURL · Standard Produktiv-ServerÜberschreibt die API-Basis-URL.

5. Bereitschaft abwarten (optional)

Wenn Ihr Code die API sofort beim Laden aufrufen will, warten Sie auf das converdino:ready-Event:

window.addEventListener('converdino:ready', function (e) {
  // e.detail.botCode enthält den Bot-Code
  // Jetzt ist window.ConverdinoWidget sicher verfügbar.
});

Für gewöhnliche Klick-Handler (onclick) ist das nicht nötig — beim Klick ist das Script längst geladen.

6. Vollständiges Beispiel

<!-- Eigener Button im eigenen Design -->
<button class="meine-pille" onclick="ConverdinoWidget.open()">
  💬 Beratung starten
</button>

<!-- Widget laden, ohne eigenen Button -->
<script
  src="https://converto-server-production.up.railway.app/converdino-widget.js"
  data-bot="IHR-BOT-CODE"
  data-launcher="off"></script>
Hinweis: IHR-BOT-CODE durch den realen Bot-Code des Slots ersetzen (z. B. Anfrage-45SW). Das Chat-Fenster, die Engine und das Verhalten bleiben unverändert — gesteuert wird ausschließlich, wodurch und wo geöffnet wird.
